# Monthly Planner — iPhone PWA

`diary-prototype/index.html`의 디자인·기능을 그대로 담고, 아이폰 홈 화면에 설치해서 오프라인에서도 열리는 웹앱 패키지입니다. 구글 계정을 연결하면 **실제 Google 캘린더 양방향 동기화**와 **Google Docs 백업·복원**이 동작합니다.

```
index.html              전체 앱 (CSS·JS·폰트 모두 이 파일 안에 있음)
manifest.webmanifest    홈 화면 설치 정보 (이름·색·아이콘)
sw.js                   오프라인 서비스 워커 (캐시 우선 + 백그라운드 갱신, 같은 출처만 캐시)
icons/                  apple-touch-icon.png 180 · icon-192 · icon-512 · icon-512-maskable
```

## 메모 본문 인라인 밑줄 · 번호 감지 확장 (mp27-v29)

- **메모도 글자 안에서 밑줄** — 위에 따로 떠 있던 pill 줄(`#dtokbar`)을 없앴습니다. 지금은
  메모를 그냥 읽을 때 본문이 `<textarea>`와 똑같은 서체·크기·행 높이(32px)·여백으로 깔린
  `div.mview`로 그려지고, 그 안의 전화번호·메일·주소가 문장 그대로 점선밑줄 토큰이 됩니다.
  밑줄을 누르면 액션 시트만 열리고(수정 모드로 들어가지 않음), 다른 글자를 누르면 그 자리에
  커서가 꽂힌 채 `<textarea>`로 바뀝니다. 글자를 다 쓰고 손을 떼면(blur·목록 이동·탭 전환)
  다시 밑줄 있는 읽기 화면으로 돌아오므로, 새로 적은 번호도 바로 밑줄이 생깁니다. 메모는
  내용만큼 자라나서 두 화면의 높이가 같고(페이지가 튀지 않음), `+ new`는 커서가 들어간 채로
  열립니다. 제목을 눌러도 시트는 열린 그대로입니다.
- **번호 감지** — 하이픈이 없어도(`01012345678` · `0534872917` · `0212345678`), 괄호가 섞여도
  (`053)4448888` · `053) 444-8888` · `(053)444-8888` · `(02)123-4567`), 대표번호도
  (`1588-1234` · `15881234` · `16xx` · `18xx`), 해외번호도(`+82-10-1234-5678` ·
  `+821012345678` · `+1-415-555-1234` · `+81 3 1234 5678`, 8~15자리) 읽습니다. 날짜
  (`2026-11-25` · `20261225` · `261225`)·시간(`14:00`)·금액(`12,000원`)은 그대로 번호가
  아닙니다. `tel:` · `sms:` · `.vcf` · `번호 복사`에는 숫자만 남기고 `+`는 맨 앞만 남깁니다
  (`(053) 444-8888` → `0534448888`).
- check 항목과 Day Modal의 인라인 밑줄은 예전 그대로입니다.

## 전화·메일·주소 · 자동 백업 · 이 날만 (mp27-v28)

- **전화 · 메일 · 주소 감지** — 일정 제목, check 항목, memo 본문에 적은 `010-1234-5678` ·
  `hello@example.com` · `서울 강남구 테헤란로 152`를 앱이 읽습니다. 제목과 check 항목에서는
  그 부분만 점선밑줄 토큰이 되어 눌리면 종이 액션 시트가 열리고(다른 글자를 누르면 예전처럼
  수정), memo 본문은 v29부터 글자 안에 그대로 점선밑줄로 앉습니다. 날짜(`2026-11-25`)·시간(`14:00`)·금액
  (`12,000원`)은 번호로 읽지 않습니다(한국 번호는 `0` 또는 `+82`로 시작 + 3~4자리 + 4자리).
- **액션 시트** — Search·Day 창과 같은 종이(`--paper`, `1px solid var(--hair)`, `×`, Escape·바깥
  누르기로 닫기). 위에 누른 값을 그대로 보여 주고, 전화는 `전화 걸기`(`tel:`) · `문자 보내기`
  (`sms:`) · `번호 복사` · `연락처로 저장(.vcf)`, 메일은 `기본 메일 앱`(`mailto:`) ·
  `Gmail로 쓰기` · `이메일 복사` · `.vcf` 저장, 주소는 `네이버 지도` · `카카오맵` · `구글 지도` ·
  `애플 지도` · `주소 복사`. `.vcf`는 UTF-8 vCard 3.0(`FN` + `TEL`/`EMAIL`)이고, 같은 곳에 적힌
  메일이 있으면 함께 들어갑니다. 연락처로 저장할 때만 `이름` 칸이 나옵니다(비우면 값이 이름).
- **반복 일정 · 이 날만** — 반복 일정의 회차에서 제목을 누르거나 `×`를 누르면 먼저
  `이 날만` / `전체 반복` / `취소`를 묻습니다. `이 날만` 삭제는 그 날짜를 `skipDates`에 넣어
  그 회차만 감추고(체크 표시도 함께 지움), `이 날만` 수정은 그 날짜를 건너뛰게 한 뒤 같은 날짜에
  반복 없는 일정 하나를 새로 만듭니다. 달력·연간 표·검색·`+N` 모두 `skipDates`를 건너뛰고,
  Docs 백업에는 `(매주) [건너뜸 2026-12-08,2026-12-15]`로 적혀 복원 때 다시 읽힙니다.
- **Google Docs 자동 백업** — Google이 연결된 상태에서 일정·check·memo가 바뀌면 4초 뒤
  조용히 같은 `Monthly Planner 백업` 문서를 다시 씁니다(백업 범위 체크박스 그대로, 기본 셋 다).
  `≡ → option`의 `Google Docs로 백업` 밑에 `자동 백업 · 방금 · Google Docs`처럼 시각이 남고,
  연결 전에는 `Google을 연결하면 자동 백업됩니다`입니다. 창·알림 없이 실패하면 마지막 백업을
  그대로 두고 조용히 넘어갑니다(만료된 토큰도 알리지 않음).

## 일정 검색 · 반복 일정 (mp27-v27)

- **mp27-v27** — 숫자만 쳐도 날짜로 읽습니다. `20261225`(YYYYMMDD) · `261225`(YYMMDD) ·
  `26.12.25`·`26/12/25`·`26-12-25`(두 자리 해) · `1225`(지금 보고 있는 해의 12월 25일) ·
  `202612`(그 해 그 달). 없는 날짜(`20260230`)는 날짜로 읽지 않습니다. 날짜·달로 읽힌 질의에는
  `…로 이동` 줄 밑에 **그날(또는 그달)의 공휴일·명절·24절기**가 함께 뜽니다
  (예: `20261225` → `2026.12.25 (금)로 이동` + `2026.12.25 (금) 성탄절 [공휴일]`,
  `20260105` → `소한 [절기]`, `202612` → 그달의 대설·동지·성탄절).
- **mp27-v25** — 검색 창 머리에서 `Search` 옆 부제(`일정 · 날짜 · 공휴일 · 절기`)를 지웠고,
  check / memo 목록 위 검색줄은 `검색` 글자 대신 달력 검색과 같은 돋보기 아이콘을 밑줄 안쪽 왼쪽에
  두고, 글자를 넣으면 오른쪽에 `×`가 나타나 지웁니다(달력 아래 패널과 `≡` 메뉴 둘 다 같은 줄).
- **검색** — 월 화면 위 `m / s` 왼쪽의 작은 돋보기 + 짧은 밑줄을 누르면 종이 검색 창이 열립니다
  (입력칸에 바로 커서, `×`로 지우기, Escape·바깥·`×`로 닫기). 제목 한 조각이나 날짜를 적으면
  바로 아래에 결과가 뜹니다. `2027-01-15` · `2027.1.15` · `2027/1/15` · `2027년 1월 15일` ·
  `1/15` · `1월 15일` · `2027-01` · `1월`을 날짜로 읽고, 날짜로 읽힌 질의에는
  `…로 이동` 줄이 함께 떠서 일정이 없는 날·달도 바로 갈 수 있습니다. 숫자만 쳐도(`20261225` ·
  `261225` · `26.12.25` · `1225` · `202612`) 같은 식으로 읽습니다.
- **공휴일 · 명절 · 24절기 검색** — `설날` · `추석` · `어린이날` · `광복절` · `정월대보름` · `단오`
  · `입춘` · `하지` · `동지`처럼 앱이 이미 달력에 적는 이름도 찾습니다. 올해를 먼저, 그다음
  작년 · 내년 · 내후년 순으로 보여 주고, 공휴일·명절은 일요일 잉크(`--sun-ink`),
  절기는 흐린 잉크로 적히며 `공휴일` · `명절` · `절기` 표가 붙습니다.
- 결과를 누르면 그 달로 넘어가 날짜 창이 열립니다(달 이동 줄은 달력만).
- **반복** — 날짜 창의 `없음 / 매주 / 매월 / 매년`. 일정 하나에 `repeat` 하나만 남고
  (`weekly`·`monthly`·`yearly`), 달력·연간 표·`+N`·검색 모두 그 날짜부터 규칙대로 펼쳐 그립니다.
  29·30·31일은 그런 날이 없는 달을 건너뛰고, 2월 29일은 다음 윤년에 다시 나타납니다.
  체크는 `doneDates[날짜]`로 회차마다 따로 남아 한 주를 체크해도 다음 주는 그대로입니다.
  Google로 올릴 때는 `recurrence: ['RRULE:FREQ=WEEKLY|MONTHLY|YEARLY']`로 나가고, 받을 때
  `RRULE`의 `FREQ`를 다시 읽습니다. Docs 백업에는 `(매주)`처럼 규칙이 함께 적혀 복원됩니다.

## 구글 연동 (실제 OAuth)

- 로그인: Google Identity Services 토큰 방식 (`https://accounts.google.com/gsi/client`),
  클라이언트 ID `298606966628-340se0j42car2becjbqks0csb17nlq2l.apps.googleusercontent.com`
- 요청 권한: `calendar` · `drive.file` · `documents` · `userinfo.email`
- 토큰은 메모리와 `sessionStorage`에만 두고(만료 60초 전에 버림), 브라우저를 닫으면 사라집니다.
- `≡` 메뉴의 **option** 탭 아래(6개 설정 아래 구분선 다음) **Google Calendar · 연결 / 지금 동기화**
  - 누른 시점에만 실행: 이 계정의 달력 목록을 먼저 받고(`calendarList`), 체크된 달력들의 올해 일정을 받아온 뒤(`events.list`), 구글에 없는 로컬 일정을 기본 달력에 올립니다(`events.insert`).
  - 달력 목록은 `≡ → option`의 `공휴일 함께 표시` 아래에 체크박스 · 색 점 · 이름으로 나옵니다. `기본 달력`은 처음부터 체크, 나머지 공유·보조 달력은 직접 체크할 때만 일정을 가져옵니다. 체크를 풀면 그 달력 일정이 달력에서 빠집니다(구글 쪽 일정은 그대로).
  - 보조 달력 일정은 달력마다 다른 잉크 색으로 그려지고, 날짜 창에서는 `· 달력이름`이 함께 붙습니다. 기본은 테마별 5색(`--cal-c0`~`--cal-c4`)이고, 공유·보조 달력의 색 점을 누르면 휴대폰의 RGB 색 팔레트가 열려 원하는 색으로 바꿀 수 있습니다(`cal.customColor`, 예 `#2e6f5e`). 그 색은 그 달력 일정의 글자·점, 그리고 그 날의 연필 동그라미까지 그대로 따라갑니다. `기본 달력`은 원래 잉크 색과 기본 연필 색 그대로입니다.
  - 일정을 고치거나 지우면 그 일정이 있던 달력으로 보냅니다(`events.patch` / `events.delete`, `calendars/{calendarId}`). 읽기 전용(`reader`·`freeBusyReader`) 공유 달력 일정은 고치거나 지울 수 없고 "읽기 전용 공유 달력 일정이에요"라고 알려 줍니다.
  - `공휴일 함께 표시`가 켜져 있으면 `ko.south_korea#holiday@group.v.calendar.google.com`에서
    그해 공휴일을 받아 기본 공휴일 목록과 합쳐 일요일 색으로 보여 줍니다(달력 목록에서는 빠집니다).
- **Google Docs로 백업** — 드라이브에서 `Monthly Planner 백업` 문서를 찾고(예전 `27 Monthly Planner 백업` 문서도 이어서 쓰고, 없으면 만들고),
  `1. 월별 일정 / 2. memo / 3. check` 세 부분을 문서 본문에 덮어씁니다.
  (읽기 `GET https://docs.googleapis.com/v1/documents/{id}`, 쓰기 `:batchUpdate`)
- **Docs에서 복원** — 같은 문서를 읽어 일정·메모·체크리스트를 되살립니다. 예전 형식(`1. 올해의 목표 … 4. check`)의 문서도 절 이름으로 찾아 읽습니다.
- **동기화 계정** 버튼 — `select_account`로 계정을 고르거나 바꾸고, 연결된 이메일을 보여 줍니다.

서비스 워커는 **같은 출처 요청만** 캐시하므로 `accounts.google.com`·`googleapis.com` 요청은 항상 네트워크로 나갑니다.

## 올리기 (호스팅)

HTTPS 주소에서만 설치·오프라인이 동작합니다. `file://`로 열면 앱은 보이지만 설치는 되지 않습니다.
구글 OAuth도 `https://` 출처가 Google Cloud Console의 **승인된 JavaScript 출처**에 들어 있어야 로그인 창이 열립니다.

- 현재 배포: <https://mimimi-107.github.io/27-planner/> (`mimimi-107/27-planner`, `main` 브랜치 → Pages)
- 그 밖에 Netlify Drop, Cloudflare Pages 등에 같은 폴더(또는 `diary-pwa.zip`)를 올려도 됩니다.

## 아이폰에 설치

1. **Safari**로 배포 주소를 엽니다 (크롬 등 다른 브라우저에서는 "홈 화면에 추가"가 앱처럼 동작하지 않습니다).
2. 하단 **공유** → **홈 화면에 추가**.
3. 홈 화면의 **Monthly Planner** 아이콘으로 실행하면 주소창 없는 전체 화면 앱으로 열립니다.

설치 후에는 비행기 모드에서도 열립니다. 일정·메모·체크리스트는 그 기기의 localStorage에 남고,
앱을 지우거나 브라우저 데이터를 지우면 함께 사라집니다. 그때는 `≡ → option → Google Docs로 백업 → Docs에서 복원`으로 되살리면 됩니다.

## 고칠 때

- `index.html`을 고치면 `sw.js`의 `const CACHE = 'mp27-v24'`를 `mp27-v25`처럼 올려 주세요. 그래야 이미 설치한 기기가 새 파일을 받습니다.
- 아이콘을 바꾸려면 `icons/`의 PNG를 같은 이름·같은 크기로 교체합니다(180/192/512, maskable 포함).
- 구글 클라이언트 ID를 바꾸면 `index.html`의 `GOOGLE_CLIENT_ID` 한 곳만 고치면 됩니다.
